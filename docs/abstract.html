Abstract

What was measured

MoCoO is a PyTorch package that combines a variational autoencoder, optional Neural ODE dynamics, and Momentum Contrast for single-cell trajectory inference and representation learning. This page is the methods companion, not a cell-state atlas.

Scope. The JBHI float carrier compiles frozen IRALL (and related) embedding exports: UMAP clouds, ARI/NMI/ASW, DRE/LSE geometry, training loss, and iLISI. It is not cell-state physical proof and does not authorize OPT-GPU / scVI / Harmony / scVelo baselines.

Package claim

Input is an AnnData count layer. The model can return a latent embedding, an optional bottleneck, and — if the ODE is on — pseudotime, velocity, and a k-NN transition matrix. Likelihoods include MSE, NB, ZINB, Poisson, and ZIP. MoCo and the ODE are optional modules, not a claimed universal optimum.

What the floats actually show

Intended scientific object: a cell’s biological state (type, trajectory) plus technical batch. Drawn object: a contrastive + ODE latent. Figs 3 and 6 already disclaim independent biological validation and validated trajectory accuracy. Fig 7 (batch of origin / batch day) is the only float whose plotted axis is a real-world technical nuisance rather than a clustering score of that embedding.

Collage floats reuse the same frozen export family. The JBHI carrier reprints one IRALL UMAP file as Fig 1A and Fig 2A — one projection, not two experiments. GPU literature baselines remain DROP: they were not run and are not claimed.
