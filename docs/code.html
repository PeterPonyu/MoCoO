The strongest badge on this leaf is the repo that already exists. Install from PyPI or clone. There is no “run on GPU” product path here, and no scVI / Harmony / scVelo scoreboard to reproduce.

GitHub PyPI
GPU DROP. OPT-GPU, scVI, Harmony, scVelo, and veloVI were not started. Do not treat missing literature baselines as zeros, and do not use this page as a GPU hire ticket.

From PyPI

pip install mocoo

From source

git clone https://github.com/PeterPonyu/MoCoO.git
cd MoCoO
pip install -e .

Minimal use

import scanpy as sc
from mocoo import MoCoO

adata = sc.read_h5ad("data.h5ad")
model = MoCoO(adata, layer="counts", loss_mode="nb", batch_size=128)
model.fit(epochs=100)
adata.obsm["X_mocoo"] = model.get_latent()

Optional ODE + MoCo flags exist on the constructor. They return embeddings and, if the ODE is on, velocity / pseudotime. Those outputs remain representations, not a certified cell-state map.
